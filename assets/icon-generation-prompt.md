# Icon generation prompt

The application icon was created with OpenAI's built-in image generation tool using this prompt:

> Create a polished icon for an application named PowerSifu, centered on a sharp lightning-bolt
> symbol that communicates intelligent battery and power-profile control. Use a genuinely
> transparent background, with one bold amber-yellow lightning bolt integrated subtly into a
> deep navy circular power-button motif and a restrained cyan accent. Keep it geometric,
> professional, crisp, and recognizable at 16×16 and 24×24. No text, letters, watermark,
> mockup, photorealism, or busy detail.

The generated master is retained at `assets/icons/powersifu.png`; package-sized derivatives are
under `assets/icons/hicolor/`.
